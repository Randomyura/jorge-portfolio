# Jorge Sunyer Guirado — Creative Developer

Portafolio interactivo con React, TypeScript, Vite y GSAP: piezas para navegar, transiciones entre pantallas, archivo de proyectos, laboratorio, objetos con volumen y fondos sensibles al cursor.

Incluye ES/EN, modo claro/oscuro, navegación con teclado, diseño adaptable a móvil y movimiento reducido.

## Ejecutar

Con Node.js 22 y pnpm 10:

```sh
pnpm install
pnpm dev
```

En Windows también se puede usar `ABRIR-DEMO.cmd` tras instalar las dependencias.

## Publicar

GitHub Pages se publica automáticamente al subir cambios a `main`. Consulta `PUBLICAR-GITHUB.md` para la configuración y las actualizaciones.

Los proyectos son espacios provisionales a la espera de imágenes y contenidos reales. El contacto prepara un borrador en la aplicación de correo del visitante.
